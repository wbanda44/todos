# 📝 Pro To-Do App

A sleek, functional, and persistent To-Do application built with **Vanilla JavaScript**. This project was designed to demonstrate DOM manipulation, state management, and local storage integration.



## ✨ Features

* **Task Management:** Add, complete, and delete tasks easily.
* **Persistence:** Tasks are saved to `localStorage`, so they won't disappear when you refresh the page.
* **Dark Mode:** A built-in theme toggle that remembers your preference.
* **Filtering:** View your tasks by status: *All*, *Active*, or *Completed*.
* **Smart Counter:** Real-time tracking of remaining tasks.
* **Batch Clear:** Quickly remove all finished tasks with one click.

## 🚀 Getting Started

No installation or build process is required! 

1.  **Clone or Download** the repository.
2.  Open the `index.html` file in any modern web browser (Chrome, Firefox, Edge, Safari).
3.  Start organizing your day!

## 🛠️ Built With

* **HTML5:** Semantic structure for accessibility.
* **CSS3:** Custom properties (variables) for theming and Flexbox for layout.
* **JavaScript (ES6+):** Pure logic without the need for external libraries or frameworks.
